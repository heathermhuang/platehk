# Plate.hk WhatsApp Introductions

Low-volume, buyer-confirmed introductions for Plate.hk. This service is deliberately separate from the auction-data Worker and the privacy-minimised 28car signal feed.

## What it does

1. A buyer opens a structured WhatsApp draft from Plate.hk and confirms the offer for seven days.
2. A self-identified seller opens the seller draft from the exact listing card.
3. The seller consents to the HK$199 introduction terms.
4. The buyer approves that specific seller before any payment or contact disclosure.
5. Stripe Checkout collects the seller fee.
6. OpenWA creates a three-party group and sends both parties its invite link.
7. The buyer must post the generated `INTRO` confirmation within 24 hours. Missing confirmation triggers one idempotent refund.
8. Plate.hk leaves a delivered group after seven days and removes contact-bearing workflow records after 30 days.

The seller is self-identified. Plate.hk does not verify legal ownership, negotiate, collect plate-purchase money, guarantee a response or sale, or perform Transport Department transfer procedures.

## Deployment

`render.yaml` provisions one Singapore-region Docker web service on Render's smallest paid 512 MB compute plan with a 1 GB persistent disk. The service uses OpenWA v5 alpha through a narrow adapter, Playwright with system Chromium, and a fixed proxy supplied through `OPENWA_PROXY_URL`. Do not activate the public controls if the canary shows memory restarts; move to `1c-2g` first.

Required Render secrets:

- `WHATSAPP_PUBLIC_NUMBER`: secondary introduction number, digits only.
- `OPENWA_PROXY_URL`: fixed proxy URL including credentials and port.
- `STRIPE_SECRET_KEY`: Stripe secret API key.
- `STRIPE_WEBHOOK_SECRET`: signing secret for `https://platehk-whatsapp-introductions.onrender.com/webhooks/stripe`.
- `STATE_ENCRYPTION_KEY`: generated by Render. Do not rotate it without migrating or intentionally discarding the encrypted state file.

After the first deploy, scan the QR printed in Render logs using the secondary WhatsApp account. The browser profile and encrypted workflow state live only on the persistent disk.

Set `INTRODUCTION_SERVICE_URL` and `INTRODUCTION_WHATSAPP_NUMBER` on the Plate.hk Cloudflare Worker only after `/health` reports WhatsApp `READY` and a test Stripe payment/refund passes. The browser uses the public number to compose drafts locally; it does not route offer details through Render before the user presses Send. Until activation, the existing direct WhatsApp flow remains active and seller-introduction controls stay hidden.
