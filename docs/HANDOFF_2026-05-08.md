## What changed

### End-to-end tests

- [playwright.config.mjs](../playwright.config.mjs)
  - New Playwright config with Chromium desktop and mobile projects.
  - Starts the Worker-compatible local server through the test `webServer`.
  - Builds Cloudflare public assets before the browser suite.
- [e2e/platehk.spec.mjs](../e2e/platehk.spec.mjs)
  - API contract coverage for `/api/v1/index.json`, `/api/search`, `/api/issues`, `/api/issue`, and `/.well-known/mcp/server-card.json`.
  - Negative API coverage for bad dataset, excessive page size, and blocked legacy PHP API access.
  - Browser journeys for homepage search, issue detail view, share poster generation, dataset switching, language switching, sort/reset, audit page filtering, docs pages, changelog, MCP docs, and manual camera search.
  - Runs `axe-core` and fails on serious or critical accessibility violations.
  - Fails on unexpected browser console errors.
- [package.json](../package.json) and [package-lock.json](../package-lock.json)
  - Added `@playwright/test` and `axe-core`.
  - Added `test:e2e`, `test:python`, and expanded `npm test` to run Python plus Playwright.

### Local runtime

- [scripts/local_worker_dev.mjs](../scripts/local_worker_dev.mjs)
  - New Node-based local shim for the Cloudflare Worker.
  - Serves static assets from `.tmp/cloudflare-public`.
  - Provides a minimal `env.ASSETS.fetch` and in-memory `caches.default`.
  - Exists because local Wrangler 4.77 hung/exited silently in this environment.
- [scripts/run_local.sh](../scripts/run_local.sh)
  - Tries Wrangler first by default.
  - Falls back to the Node Worker shim when Wrangler cannot become healthy.
  - Can force the shim with `PVRM_LOCAL_RUNTIME=node`.

### Fixes found by QA

- [cloudflare-worker/src/api.mjs](../cloudflare-worker/src/api.mjs)
  - Route dispatch now awaits async handlers inside the shared `try/catch`, so async `ApiError` failures return controlled API responses instead of leaking as 500s.
- [cloudflare-worker/src/index.mjs](../cloudflare-worker/src/index.mjs)
  - CSP `connect-src` now includes Google font endpoints used by the page.
  - HTML response rewriting now deletes stale `content-length` after replacing production origins with the local origin, avoiding truncated local/staging HTML.
- [audit.html](../audit.html)
  - The horizontally scrollable audit table region is keyboard focusable and labelled.
- [index.html](../index.html)
  - The search results table wrapper is keyboard focusable and labelled.
  - Note: this file also had pre-existing unrelated local changes around mobile layout/result rendering. Review before staging the whole file.

### Security and docs hygiene

- [scripts/check_security.sh](../scripts/check_security.sh)
  - Uses `PYTHON_BIN` with a `python3` default.
  - Skips dependency audit cleanly when the active Python runtime is below 3.10, because current requirements need Python 3.10+.
  - Still runs the secret scan and still supports `CHECK_SECURITY_SKIP_DEPS=1`.
- [README.md](../README.md)
  - Quick Start now states Python 3.10+ as the prerequisite.
- [.gitignore](../.gitignore)
  - Ignores `playwright-report/`.

- Local `php` is missing, so one PHP-dependent workflow/release check is skipped locally. Run it in CI or on a machine with PHP before release.

- Wrangler 4.77 did not become healthy locally. The Node shim is for local dev/test resilience, not a replacement for the Cloudflare deploy path.
- The generated Playwright HTML report was removed after testing and is ignored going forward. The QA markdown note at `.gstack/qa-reports/qa-report-127-0-0-1-2026-05-08.md` is ignored.
